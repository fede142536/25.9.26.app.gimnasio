# App Gimnasio — Musculación

App web de un solo archivo (`index.html`) para registrar entrenamientos de musculación.

- **Hoy:** registrar peso y reps por serie, con timer de descanso (sonido + vibración) y detección de PRs.
- **Rutina:** cargar días y ejercicios (series, reps, descanso).
- **Progreso:** historial y récord por ejercicio.

Los datos se guardan en `localStorage` del navegador (solo en ese dispositivo).

## Uso

Abrí `index.html` en el navegador, o serví la carpeta con cualquier servidor estático:

```sh
python3 -m http.server 8000
```
